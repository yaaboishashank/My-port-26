# Shashank Sharma — Developer Portfolio

My personal portfolio showcasing my projects, technical skills, and journey as a Software Developer.

I enjoy building interactive interfaces, adding thoughtful animations, and connecting them with backend functionality. This portfolio brings that interest together through a responsive design and smooth transitions.

## Tech Stack

- **Frontend:** React.js, Vite, JavaScript
- **Styling:** Vanilla CSS
- **Animations:** GSAP, ScrollTrigger, ScrollSmoother
- **Backend:** Node.js, Express.js
- **Architecture:** Component-based frontend and MVC backend
- **Deployment:** Render

## Features

- Responsive layout with dark and light themes
- Smooth scrolling and animated sections
- Interactive technical skills section
- Project previews and detailed project dialogs
- Animated technology logo strip
- Social profiles and contact links
- Reduced-motion support

**HyperClip** — A video-sharing application featuring video transcoding, authentication, and a creator dashboard.
